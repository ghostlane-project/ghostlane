### The app is now Ghostlane

Same app, same code, new name and a new icon. Every platform moves together: the home screen, the notification, the VPN profile on iOS, the installed application on the desktop. Your server lists, settings and the connection you are on carry over untouched; the desktop and Android updater keeps following this repository under its new address.

On macOS the installed application is now Ghostlane.app, and the tunnel daemon inside it registers under the new bundle. If the system asks once more to allow it in System Settings → General → Login Items & Extensions, that is why.

Why the rename: the client and the ProofKit marketplace are two different things, and the app is a client for any provider's servers. It now says so in its name.
