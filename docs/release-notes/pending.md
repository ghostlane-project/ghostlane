### Linux servers: the ghostlane command

Ghostlane now runs headless on Linux: one `ghostlane` binary for amd64, arm64 and armv7, packaged as deb, rpm, apk and Arch packages plus a tarball, with a signed installer (`install.sh` on the release page). Add your subscription with `ghostlane add`, pick a country with `ghostlane connect DE`, and the service joins that country's olcRTC rooms with failover between carriers, reconnecting after a reboot. Two modes: `--proxy` serves a local SOCKS5/HTTP proxy with no privileges; `--tun` routes the whole machine while SSH and the machine's other services keep answering on its public address. It connects VLESS Reality, Hysteria2 and XHTTP lines from the same lists as well, with failover between all of them; in tun mode a server is proven through a local proxy before the machine is routed through it. The CLI is GPL-3.0-or-later because it links sing-box; see `docs/cli.md`.
